# opencode_bashbord

OpenCode Go 订阅额度跟踪工具：通过桌面宠物或置顶悬浮球快速查看剩余额度。

## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature>/` — no remote, no CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary, unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
